  • 具体的工程产出物（Work Delivered）
  • 算力消耗指标（Token Consumption）

本文由此出发，全面盘点从 Prompt 到 Skill，再到“个人记忆系统”的范式变迁。

技术实践的阶梯式演进

SECTION II. EVOLUTION

项目复杂度呈现清晰的三级递进关系，每一步均是对 AI 控制力的重塑：

  • 第一阶 (启蒙与单点)： 以提示词与生图起步。通过 Vibe Coding 产出 140+ HTML 网页（桌面时钟、血压工具）。
  • 第二阶 (迭代与中等复杂度)： 深度交流的产物。例如“医院住院系统”原型，历经十余次重构，探索大模型在微调中的极限。
  • 第三阶 (系统化与独立应用)： 全权利用 Kiro / ClaudeCode / Trae 落地“电子药箱”（含说明书、过期预警）。

当前的现实壁垒： 遭遇算力（顶尖模型额度消耗快）与设备（Windows CLI 限制，向往 Mac 环境）的双重瓶颈。

关于 Skill 的哲学重构

SECTION III. SKILLS DECONSTRUCTED

思维的原子化

Skill 不仅是任务载体，更是人类思考逻辑的切片。复杂的任务（如考研数据分析）被强制拆解为：
信息爬取 → 向量化处理 → 极值计算 → 多模态报告输出

算力驱动定律

弱模型执行 Skill 效率极度低下；顶尖模型配合 Agent，甚至可实现“无 Skill”运作。

机器的长效记忆

将 AI 在执行任务（如读取飞书文档）中踩坑、报错的漫长过程固化为 Skill。这本质上是在为 AI 建立避免重复犯错的记忆系统。

独立创见

独创了首个结合中医体系的健康管理 Skill，以及深度挖掘用户认知的知识提取 Skill。

技术中立：稳定性与奥卡姆剃刀法则

SECTION IV. METHODOLOGY
“能用 Python 脚本解决的事情，就不要动用 AI Agent 去处理。”

算力经济学悖论：

  • 案例：处理长篇 Markdown 文档的“中英文自动加空格”。
  • 若调用大模型：极度消耗 Token，效率低下且存在不确定性。
  • 若调用 Python 脚本：零 Token 消耗，绝对稳定，杀鸡焉用宰牛刀。

对工具的祛魅：

无需神化 OpenClaw（小龙虾）。它能做的事 ClaudeCode 都能做，其核心价值仅在于打破大厂壁垒：无任务合法性监视、免排队 API 调用。

终极命题：个人记忆系统的时空架构

SECTION V. THE MAGNUM OPUS

超越当前开源社区中充斥整活属性的“同事/前女友复刻 Skill”，构建严肃的数字分身底座，需横跨三大维度：

  • 过去 (Past)： 回溯并存储个人十年甚至半生的底层记忆与数据。
  • 现在 (Present)： 矩阵化记录（晨间规划 + 运动健康 + 学习记录 + 睡前复盘）。
  • 未来 (Future)： 引入 Github Mirofish 舆情预测算法机制。基于个人的历史数据参数，对未来的决策与行为结果进行精准的沙盘推演。
“AI 时代加速了万物的发展，也同样加速了人类对于自我宿命与世界理解的解构。”

前沿深水区：底层协作与调度

SECTION VI. FRONTIER EXPLORATION

超越 Vibe Coding，向机器劳动力的深度调度进军：

  • Agent 协作： ClaudeCode Agents Team 的内部并行通信，实现子代理的自治沟通与合并输出。
  • Harness (数字驾驭)： 探讨控制权归属，参考中国古典政治“三省六部制”架构，对 AI 职能进行政体化管理与权限约束。
  • CLI 终局革命：
    以 ClaudeCode 为大脑，联合 Gemini / CodeX 为执行器的多端协同。
    “过去的 CLI 是写给人看的；现在的 CLI 纯粹是为 AI 调用的。”
