自揭老底：
我到底用 AI 做了哪些事儿？

—— 关于 Token 消耗与 AI 协作范式的深度盘点 ——

汇报人：王晨 (晨) | 2026年4月

研究起因与思考

  • 源起：受 Kimi PM 启发，重新审视 Token 消耗量与实际产出的关系。
  • 启蒙：从最初的提示词（Prompt）策略与 AI 生图视觉审美切入。
  • 演进：经历“提示词 -> 技能（Skill） -> 养龙虾（Agent）”的完整进化路径。
思考：Token 的消耗代表了人机协同的深度。

Vibe Coding：140+ 网页实验

通过 Claude 与 Gemini 的深度交流，将创意转化为功能实体：

  • 医院住院系统原型：历经十多次迭代，打磨交互细节。
  • 电子药箱（医药管理系统）：记录使用说明、保质期及分类，解决家庭用药痛点。
  • 审美实体化：开发数据卡片生成工具，实现设计美学的快速复刻与下载。
关键工具：ClaudeCode / Trae / Kiro (Spec 模式)

Skill：思维的模块化革命

  • 原子化拆解：以考研数据分析为例，将任务细化为获取、清洗、向量化、报告产出。
  • 记忆系统化：将踩过的坑（如飞书 CLI 部署报错）总结成 Skill，赋予 AI“长期记忆”。
  • 健康管理体系：首创融合“运动、健身、数据分析、中医”四条线的健康 Skill。
见解：Skill 的本质是人类观察事物角度的重塑。

技术选择：稳定性高于一切

  • 杀鸡焉用宰牛刀：能用 Python 脚本解决的（如中英文空格处理），决不动用 Agent。
  • 解密“小龙虾” (OpenClaw)：相比大厂工具，OpenClaw 具备无排队、自由度高、无任务监视的优势。
  • 模型优先论：没有技巧，最好的技巧就是使用最顶尖的模型。
局限：资金与设备（渴望 Mac 系统）是当前的主要瓶颈。

个人记忆系统：数字化分身

基于“过去、现在、未来”三个维度的宏大构想：

  • 过去：生命历史的数字化存档（工程量巨大的回忆录）。
  • 现在：通过日常规划、运动、学习、记录四类 Skill 实现实时记录。
  • 未来：借鉴 Mirofish 项目，利用历史数据进行个人发展与决策预测。
核心理念：记忆系统是每一个人在 AI 时代的至关重要资产。

前沿探索：Agent 协作与驾驭

  • Harness (驾驭)：探索“人驾驭 Agent”或“Agent 相互驾驭”的深层底层。
  • Agent 协作：向往“大脑（ClaudeCode）+ 执行助手（Gemini/CodeX）”的多 CLI 联动方案。
  • CLI 的角色：命令行窗口正在从“给人看”转向“给 AI 看”。
愿景：在 Windows 阵地之外，探索更纯粹的 AI 生态。

汇报总结

加速理解世界

AI 时代不仅加速了万物发展，更加速了我们对于自身的理解。

“做网页、做 Skill、做项目，三者相通，终归于解决问题的稳定性。”
