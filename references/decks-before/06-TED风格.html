我使用 AI 的三个阶段

01

提示词时代

一问一答，尝试寻找神级指令。
探索 AI 的边界与局限。
02

技能时代

构建工作流 (Workflow)。
结合上下文，封装专属工具。
03

智能体时代

自主爆发 (Agents)。
设定目标，让 AI 独立规划与反思。
PHASE 01

试图用一句话解决
所有问题。

  • 交互模式： 直接向大模型索要最终结果。
  • 典型场景： “帮我写一篇1000字的爆款文章”。
  • 真实体感： 看了无数技巧，但输出总是“缺乏灵魂”。
  • 致命缺陷： 逻辑发散不受控，极具随机性。

Prompt 不是万能的。

大模型写不出你心里的文章，根本原因是
缺少上下文 (Context)。
单靠指令，无法弥补隐性知识与业务流程的信息差。
PHASE 02

引入工作流
(Workflow)

  • 核心转变： 从“对话框许愿” 走向 “工程化拆解”。
  • 运作机制： 将任务拆分成节点，固化为可复用的“技能”。
  • 工具生态： 使用 Coze, Dify 等平台编排 Pipeline。
  • 终极优势： 结果可控、输出稳定，化身生产力工具。

构建专属技能

沉浸式翻译器

不再只是简单的字面互译。

强制 AI 先输出思考过程与语境分析，再进行多语言精准适配，实现“信达雅”。

SEO 关键词助手

将复杂的 SEO 竞品爬取与分析流程，封装成团队小白都能一键运行的后台 SOP。

但工作流依然是线性的。

  • 异常即崩溃：遇到预设外的输入，流程中断。
  • 无法自省：无法根据外部 API 的反馈自我调整。
  • 依赖人工：仍需人类“点击运行”或填入大量参数。
  • 范式隐喻： 放弃手把手教，建立自我循环的生态（养龙虾）。
  • 人类身份： 养殖者。提供计算环境，下发工具库权限。
  • AI 身份： 独立数字员工。给定目标后自主规划、调用、反思重试。
PHASE 03

释放自主智能体
(Agents)

实践：全自动内容工厂

STEP 1

数据捕获

Agent 自动轮询 RSS，调用爬虫进行内容提取与数据清洗去重。
STEP 2

推理重构

LLM 独立评估资讯价值，自主思辨，撰写符合品牌语调的长文。
STEP 3

全自动发布

调用 CMS API，将渲染排版完毕的内容推送到指定平台。Zero-touch。

如何养好这只“龙虾”？

1. 给足工具权限

必须赋予联网搜索、文件读写、甚至是代码解释器权限。

可用 API 的丰富度，决定了 Agent 能逾越多少非结构化的障碍。

2. 设定严密边界

目标必须具象且可测量，严禁下达“帮我赚钱”这类抽象的死循环指令。

设置超时捕获，防止模型在推理死胡同里烧光算力。

算力代价

进入这个阶段，最直观的现象是：

Token 消耗量
指数级飙升。

独立价值

海量 Token 背后是它在自主执行逻辑推理、工具调用与失败重试。

人类卸下驱动器身份，
AI 成为真正的数字劳工。

回到最初的命题：Token 消耗量到底衡量了什么？

它客观映射了你使用 AI 的深度：
从 "知识百科"
跃迁至 "全天候数字员工"。
