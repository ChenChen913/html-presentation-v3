~/presentations/07_limitations.md

dmesg | grep -i limits

工作流大幅提升了稳定性，但本质仍是 线性和静态的决策树。

  • 异常中断： 遇到代码中没有 `try-catch` 的预设外异常，流程直接崩溃。
  • 状态僵化： 无法根据外部 API 的实时反馈动态调整下一步走向。

# 1. Tool Empowerment (工具授权)

给予充分的环境交互能力

必须赋予联网搜索、文件系统访问、甚至是 Code Interpreter 执行环境。

严格设置 Max_Iterations 和超时异常捕获，防止模型在推理死胡同中耗尽算力。

The transition from prompt-based interactions to autonomous intelligent agents represents a profound paradigm shift in software architecture. While traditional Large Language Models (LLMs) rely heavily on meticulously crafted prompts to generate single-turn responses, modern workflow orchestrations and agents introduce multi-step reasoning, API tool utilization, and self-reflection loops.

This presentation explores the trajectory of this evolution, highlighting the fundamental limitations of static pipelines and emphasizing the exponential increase in computational token consumption as a necessary trade-off for true autonomy. The future of AI lies in its capability to execute background daemons as an active digital workforce.
