# 03 · 渐进式披露 (Progressive Disclosure)

讲演不是把笔记贴墙上，而是**控制信息出现的节奏**。本 skill 强制两套渐进：整本（叙事层）和单页（视觉层）。

## 1. 整本叙事：7:2:1 比例

```
[封面] [背景 / 钩子] [目录 / 总览]
   ↓
[阶段 1] 章节封 + 痛点 + 引入 + 1-2 支撑 + 小结
[阶段 2] 章节封 + 痛点 + 引入 + 1-2 支撑 + 小结
[阶段 3] 章节封 + 痛点 + 引入 + 1-2 支撑 + 小结
   ↓
[总结 / 回到最初命题] [致谢 / Q&A]
```

| 角色 | 页数 | 比例 | 模板 |
|---|---|---|---|
| 封面 + 引子 | 1-2 | 5-10% | cover + 钩子页 |
| 阶段封 (3 个) | 3 | 18% | 单大字 + 数字编号 |
| 正文支撑 | 10-12 | 60-70% | split / grid / quote / 公式 / 配图 |
| 总结 + 致谢 | 2 | 12% | quote + final thanks |

> 14-17 页是体感最佳区间；超过 20 页几乎一定要拆 deck。

## 2. 单页视觉：4 段式动画

每页内容元素按下列顺序进场（参考 `references/decks/01-创意活泼风.html` 等 deck 的 `.reveal` / `.reveal-fade` / `.reveal-scale` 类）：

```
T+0ms     装饰层 fade-in（背景 / 模糊球）     400ms
T+80ms    主标题 fade-up                       500ms
T+200ms   副标 / 编号 stagger                  400ms
T+320ms   正文 / 列表 / 卡片 stagger           500ms
T+600ms   callout / 强调点 scale-up            400ms
```

**实现代码模板**：

```css
.reveal        { opacity: 0; transform: translateY(24px); transition: all .5s ease; }
.reveal.in-view, .slide.visible .reveal { opacity: 1; transform: translateY(0); }
.reveal-scale  { opacity: 0; transform: scale(.92); transition: all .6s cubic-bezier(.34,1.56,.64,1); }
.slide:nth-child(1) .reveal { transition-delay: 0ms; }
.slide:nth-child(1) .reveal:nth-child(2) { transition-delay: 80ms; }
/* ...  按 nth-child 累加 80-120ms  */
```

**用 IntersectionObserver 触发**，进入视口 50% 才播放一次，**不要循环**。

## 3. 一页只讲一个命题（Rule of One）

每张幻灯片**只**回答观众脑中这一个问题：

> "这张图让我必须记住的一个点是什么？"

- 标题就是这个点的**完整句子**（不是"产品介绍"这种抽象名词）
- 副标 / 列表 / 图片都是**支撑这个句子**的证据
- 出现 2 个并列主张 = 拆 2 页

## 4. 4 种典型渐进节奏

### 4.1 论证型（章节封 → 痛点 → 引入 → 支撑 → 小结）

```
[第 N 阶段] - 数字 + 大字
[痛点]      - 一句话犀利反问 + 1 个对比
[引入]      - 解决思路一句话 + 缩略图
[支撑 1]    - 案例 / 数据 / 公式
[支撑 2]    - 另一个角度的案例
[小结]      - 一句话结论，回到阶段主张
```

### 4.2 对比型

左旧右新 / 上A下B；标题**显式**对比（"X 不再是 Y" / "从 A 到 B"）；至少 3 个维度差异。

### 4.3 列表型

- 大标题
- 2-4 个并列卡片，每卡 = 图标 + 标题 + 1 句话说明
- 卡片间距统一 24-32 px

### 4.4 引文型

- 一句 ≥ 30 字的核心引文
- 引文下方 1 行出处（小、灰）
- 装饰只用一个：背景色块或大字号引号

## 5. 节奏禁忌

| 禁忌 | 反例 | 改进 |
|---|---|---|
| 一上来就堆数据 | 第 1 页 5 个数字 | 数字留着做总结；开头给钩子 |
| 全程同节奏 | 每页都是「标题 + 3 个 bullet」 | 至少每 4 页换 1 种 layout |
| 视觉无重音 | 整本字号一样大 | 关键句 1.5x，副标 1.2x |
| 动画无意义 | 每个段落都从左边滑入 | 用 fade + 微位移，少于 3 种 |
| 颜色无主导 | 每页一个主色 | 整本 1 个主色 + 1 个强调色 |

## 6. 节奏速查

| 页数 | 推荐动画时序 | 列表项数 |
|---|---|---|
| 1 (封面) | 标题 600ms 后副标 400ms | 0 |
| 2-3 (引子) | 全场 fade-in 无 stagger | 1 段引用 |
| 4-15 (正文) | 标题 → 副标 → 列表 stagger 80ms | 3-5 项 |
| 16-17 (总结) | 标题 big-scale，列表淡出 | 1-2 句引文 |
