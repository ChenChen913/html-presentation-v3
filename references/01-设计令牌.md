# 01 · 设计令牌 (Design Tokens)

每一种美术风格都内嵌在对应 deck 的 `<style>` 的 `:root` 里。本文档**只**汇总跨风格的硬性规则（坐标系、字号梯度、断点），具体配色 / 字体请**直接读 deck 的 `:root`**。

## 坐标系（全 deck 通用）

| 项 | 值 | 备注 |
|---|---|---|
| 基准分辨率 | 1280 × 720 px | 16:9 |
| 基准缩放 | `Math.min(vw/1280, vh/720)` | `ScaleController` 注入到 `.slide-inner` |
| 移动端 | `max-width: 767px` 走 `100vw` + 自然高 | 见各 deck 的 `@media` |
| 装饰 z-index | 0 | 必须 `pointer-events: none` |
| 内容 z-index | 10 | 始终在装饰之上 |
| 控件 z-index | 100 | nav-dots、keyboard-hint |

## 字号梯度（投影稿，不是屏幕稿）

```
封面主标题    72 - 96 px
章节封 / 大标  56 - 64 px
页面主标题    40 - 48 px
副标 / 强调   28 - 32 px
正文 (中文)   28 - 40 px   默认 32px；小会议室 28，大会议室 36-40
列表项        28 - 32 px
引用 / 引文   28 - 36 px   中文禁用斜体，用加粗 / 颜色 / 色块区分
脚注 / footer  20 - 24 px   灰，且不浅于 #767676（白底）
数学公式      28 - 40 px   display="block"
代码块        20 - 24 px   monospace
```

> 中文正文**不低于 28px**。这是投影稿——22-26px 在屏幕上看刚好，投出来最后一排就没了。
>
> 行高：正文 1.5-1.6，标题 1.15-1.25。
>
> 中文与英文混排时，西文比中文小 **1-2 px** 视觉上才平衡。

> 完整硬数字与依据见 `07-中文排印与硬规则.md`。

## 颜色规则

- **永远先定背景**，再定文字与点缀色。背景要么纯色、要么 1 张图、要么 ≤2 个色块的渐变。
- 正文与背景对比度 ≥ 4.5:1；大文本（≥24px，或 ≥18.66px 且加粗）可降到 3:1。
- 白底上的辅助文字**不浅于 `#767676`**；避免纯黑纯白，用 `#1A1A1F` / `#F5F5F7`。
- 强调色若既当文字又当底色，压暗到两个方向都达标即可一次解决；
  需要保留鲜亮装饰色时另开 `-ink` 变体专供文字（见 05 的 `--comic-blue-ink`、07A 的 `--nobel-gold-ink`）。
- 同 deck 内主色 ≤ 3 种 + 1 种点缀；超过 3 种必然花。
- 浅色 deck（01-05）: 文字用 `--text-main` 一种，**不要**给每个 box 各取一色。
- 深色 deck（06、07 部分）: 白字 + 1 个强对比色块（TED 红、牛津蓝），**不要**全用灰。
- 强调字**不要写死白色**——遇到白底页就是 1.00:1 完全隐身，要按底色调度。

## 字体规则

**中文系统栈是主力，不是兜底**——Google Fonts / jsdelivr 在国内常不可达，
CDN 字体一旦加载失败，字体栈里没有中文回退就会掉成各机器不同的字形，排版当场散架。

```css
--font-sans: system-ui, -apple-system, "Segoe UI", "PingFang SC",
             "Hiragino Sans GB", "Microsoft YaHei", "Source Han Sans SC",
             "Noto Sans CJK SC", sans-serif;
```

- 任何 `--font-*` 都必须在末尾追上这套中文栈，哪怕首选是 CDN 字体
- 中文标题可用思源宋体 / 霞鹜文楷 / 站酷快乐体等免费 CDN 字体，但**必须**做 `unicode-range` 分片 + `font-display: swap`
- 英文标题优先用衬线（学术风）或粗无衬线（TED / 极客）
- 数学公式用 `Cambria Math` 或 `Latin Modern Math` 兜底
- **禁用** Inter / Poppins / Roboto / Montserrat / DM Sans / Geist（AI 生成物的典型标记）
- **字重封顶 700**；且必须显式 `b, strong { font-weight: 700 }`——UA 的 `bolder` 在父级 700 时解析成 900
- **中文禁用 `font-style: italic`**，浏览器会合成伪斜体

## 阴影 / 模糊 / 装饰

- 阴影：浅色 deck 用 `box-shadow: 0 10px 30px rgba(0,0,0,.1)` 通用
- 玻璃面板：`backdrop-filter: blur(20px)` + `background: rgba(255,255,255,.65)` + 1px 白边
- 模糊球：固定 `filter: blur(80px)` + `opacity: .4-.6`，不要叠 3 层以上
- 形状装饰：每页 ≤ 3 个，**至少 1 个角在视口外**（不全收）

## 跨风格公约

1. 任何 deck **都**包含 `class ScaleController` + `class SlidePresentation` 两条骨架代码（`01-07` 都是这两套）。
2. 任何 deck **都**包含 nav-dots（固定右侧中部）。
3. 任何 deck **都**给内容元素加 `contenteditable="true"` — 演讲者可现场改字。
4. 任何 deck **都**给移动端写 `max-width: 767px` 的退路。
