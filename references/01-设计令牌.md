# 01 · 设计令牌 (Design Tokens)

每一种美术风格都内嵌在对应 deck 的 `<style>` 的 `:root` 里。本文档**只**汇总跨风格的硬性规则（坐标系、字号梯度、断点），具体配色 / 字体请**直接读 deck 的 `:root`**。

## 坐标系（全 deck 通用）

| 项 | 值 | 备注 |
|---|---|---|
| 基准分辨率 | 1280 × 720 px | 16:9 |
| 基准缩放 | `Math.min(vw/1280, vh/720)` | `ScaleController` 注入到 `.slide-inner` |
| 移动端 | `max-width: 767px` 走 `100vw` + 自然高 | 见各 deck 的 `@media` |
| 装饰 z-index | 0 | 必须 `pointer-events: none` |
| 内容 z-index | 10 | 始终在装饰之上 |
| 控件 z-index | 100 | nav-dots、keyboard-hint |

## 字号梯度（参考线，可按风格微调）

```
封面主标题    72-96 px   粗体 / 居中
章节封 / 大标  56-72 px
页面主标题    40-48 px
副标 / 强调   28-32 px
正文 (中文)   22-26 px   line-height 1.6-1.8
正文 (英文)   20-24 px   line-height 1.5-1.7
列表项        20-24 px
引用 / 引文   26-32 px   斜体优先
脚注 / footer  14-16 px   灰
数学公式      28-40 px   display="block"
代码块        14-18 px   monospace
```

> 中文与英文混排时，西文比中文小 **1-2 px** 视觉上才平衡。

## 颜色规则

- **永远先定背景**，再定文字与点缀色。背景要么纯色、要么 1 张图、要么 ≤2 个色块的渐变。
- 正文与背景对比度 ≥ 4.5（WCAG AA）。大字号可降到 3.0。
- 同 deck 内主色 ≤ 3 种 + 1 种点缀；超过 3 种必然花。
- 浅色 deck（01-05）: 文字用 `--text-main` 一种，**不要**给每个 box 各取一色。
- 深色 deck（06、07 部分）: 白字 + 1 个强对比色块（TED 红、牛津蓝），**不要**全用灰。

## 字体规则

- 中文标题优先用思源宋体 / 霞鹜文楷 / 站酷快乐体等免费 CDN 字体
- 英文标题优先用衬线（学术风）或粗无衬线（TED / 极客）
- 数学公式用 `Cambria Math` 或 `Latin Modern Math` 兜底
- 所有字体导入必须带 `font-display: swap`，并提供 system fallback（`'Microsoft YaHei'` / `Arial` / `serif`）

## 阴影 / 模糊 / 装饰

- 阴影：浅色 deck 用 `box-shadow: 0 10px 30px rgba(0,0,0,.1)` 通用
- 玻璃面板：`backdrop-filter: blur(20px)` + `background: rgba(255,255,255,.65)` + 1px 白边
- 模糊球：固定 `filter: blur(80px)` + `opacity: .4-.6`，不要叠 3 层以上
- 形状装饰：每页 ≤ 3 个，**至少 1 个角在视口外**（不全收）

## 跨风格公约

1. 任何 deck **都**包含 `class ScaleController` + `class SlidePresentation` 两条骨架代码（`01-07` 都是这两套）。
2. 任何 deck **都**包含 nav-dots（固定右侧中部）。
3. 任何 deck **都**给内容元素加 `contenteditable="true"` — 演讲者可现场改字。
4. 任何 deck **都**给移动端写 `max-width: 767px` 的退路。
