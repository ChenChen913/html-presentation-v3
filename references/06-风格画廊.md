## 选风格的三步

1. **受众是什么画像？**
   - 学术 / 权威 → 03 / 07
   - 商业 / 大众 → 01 / 02 / 06
   - 技术 / 极客 → 04
   - 教学 / 童趣 → 05

2. **情绪基调？**
   - 兴奋 / 动感 → 01 / 05
   - 高级 / 克制 → 02 / 06
   - 严谨 / 中性 → 03 / 07
   - 直白 / 效率 → 04

3. **有没有品牌色？**
   - 有 → 找最接近的 deck，把品牌色替换 token
   - 无 → 用主色 + 1 强调色 = 4:1 比例

## 各风格核心 token

> 完整 token 列表在对应 deck 的 `<style>` 段。这里只列**不可动**的硬约束。

### 01 创意活泼风（新粗野主义）

- 字体：YouSheBiaoTiHei（标题）+ AlibabaPuHuiTi（正文）
- 主色：黑（描边/字）+ 黄（强调块）+ 红/蓝/粉（次要）
- 描边：6-8px 实心黑边
- 阴影：12-16px 硬阴影（无 blur）
- 装饰：色块 / 圆 / 矩形 / 网点 — 必须有 1 个色块"出框"

### 02 科技液态玻璃风

- 字体：MiSans（标题）+ Noto Sans SC（正文）
- 主色：白底 + 蓝/紫/粉渐变光晕
- 玻璃：rgba(255,255,255,.65) + 1px 白边 + 20px blur
- 模糊球：3 个不同色，opacity .4-.6
- 禁止用 sharp 阴影；只能用 blur 模糊

### 03 学术汇报汇报风

- 字体：Times New Roman / Noto Serif SC（标题）+ LXGW WenKai（正文）
- 主色：白底 + 牛津蓝 #0A3663 + 学术红 #8B1A1A
- 装饰：≤ 1 个（一般只有顶部 header 双线）
- 公式：用 `<math>` 原生 MathML
- footer：自动注入"会议名 + 页码"

### 04 清晰极客风（Terminal）

- 字体：Fira Code（代码）+ Noto Sans SC（正文）
- 主色：亮绿底 #EEF4EE + 暗绿 #203B26 + 高亮 #298F3D
- 容器：仿 Terminal 框（红黄绿三圆点 + 路径头）
- 装饰：canvas 跑 Matrix 雨
- 标题用 `> command` 形式

### 05 可爱漫画风

- 字体：ZCOOL KuaiLe（标题）+ Yozai（手写正文）
- 主色：黄底 #FFDE00 + 黑边 + 4-5 配色点缀
- 描边：6-10px 漫画感粗黑边
- 装饰：圆点底纹 + 倾斜框 + 爆炸框
- 禁止用衬线字（会破坏童趣感）

### 06 TED 风格

- 字体：Alibaba PuHuiTi（中文标题）+ Noto Sans SC（正文）
- 主色：黑底 + 红 #E62B1E + 白
- 装饰：1 种（通常是大色块对开）
- 标题：**字重上限 700**（800/900 会让中文糊成黑块），1.1-1.25 line-height
- 重点：3-5 词大字 + 一句话解释

### 07 诺贝尔风格

- 字体：Times New Roman / Noto Serif SC（衬线全程）
- 主色：纸白 #FDFDFD + 牛津蓝 #002147 + 胭脂红 #8A1538
- 装饰：≤ 1 个（通常只有顶部细线 + 期号）
- 公式：必须用 `<math>` MathML
- 备选：07 的 0X 系列是单页式（.active 切换），适合**讲演时手动控制**的场合

## 不确定时的兜底

- 客户没要求 → **02 科技液态玻璃风**：百搭、不出错、5 年不过时
- 客户说"正式一点" → **07 诺贝尔风格**
- 客户说"活泼一点" → **01 创意活泼风**
- 客户说"接地气" → **05 可爱漫画风** 或 **04 清晰极客风**
- 客户说"震撼" → **06 TED 风格**
