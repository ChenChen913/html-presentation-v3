# 04 · 幻灯片模板 (Slide Layouts)

8 种经过实测的 layout。每种都给：用途 / HTML 骨架 / 适用风格 / 注意点。

> 7 个参考 deck 都用了这些 layout 的子集；选 deck 之前先看哪几种 layout 用得最多。

## 1. Cover（封面）

**用途**：第 1 页 / 整本的开场。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner cover-slide">
    <h1 class="title-main" contenteditable>主标题</h1>
    <p class="title-sub" contenteditable>副标 · 一行 · ≤ 24 字</p>
    <div class="bg-shape" style="..."></div>
  </div>
</section>
```

**风格映射**：
- 01: `title-main` 80px + 黄色色块 + 黑色边框
- 02: 玻璃面板中央 + 渐变背景
- 03: 双行衬线标题 + 作者 + 日期
- 06: 全黑背景 + 白色大字 + 红色细线

**注意点**：
- 主标 ≤ 12 个字（中文）/ 6 个单词（英文），超了拆两行
- 副标必须有，承担"承诺看完这本就懂什么"的角色
- 装饰元素 ≥ 1 个，**主体绝不能只是白底 + 标题**

## 2. Hook（钩子 / 引子）

**用途**：第 2-3 页。制造好奇 / 给背景。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner">
    <div class="quote-card reveal">
      <div class="quote-mark">"</div>
      <p class="quote-body" contenteditable>一句反问 / 数据 / 引用</p>
      <p class="quote-source">— 出处</p>
    </div>
  </div>
</section>
```

**注意点**：
- 这页通常不用 bullet，全靠一句有张力的话
- 字号比正文大 1.2-1.5x（30-40px）
- 不要装饰超过 2 个，否则抢戏

## 3. Section Header（章节封 / 阶段封）

**用途**：每个阶段的首页。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner">
    <span class="section-num reveal-scale">01</span>
    <h2 class="section-title reveal" contenteditable>第一阶段：XX</h2>
    <p class="section-sub" contenteditable>一句话副标</p>
  </div>
</section>
```

**注意**：
- 数字 96-160px，标题 56-72px，副标 24-32px
- 数字与标题之间 margin 0；用同一行 baseline 节奏
- 装饰只放背景色或 1 个形状

## 4. Split（左右分栏 / 上下分栏）

**用途**：定义 + 解释 / 旧 vs 新 / 概念 + 例子。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner">
    <header class="slide-header">
      <h2 class="slide-title">页面主张</h2>
    </header>
    <div class="slide-content layout-split">
      <div class="reveal"><h3>主张方</h3>...</div>
      <div class="reveal text-body">3 个 bullet 支撑</div>
    </div>
  </div>
</section>
```

**注意**：
- 左右比例默认 1:1，论据强时改 4:6
- `gap: 60px` 是默认值，太窄会撞
- 不要在左 / 右侧再分栏（再分用 Grid）

## 5. Grid（卡片网格 2×2 / 1×3）

**用途**：并列 3-4 个同等重要的概念 / 工具 / 案例。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner">
    <header class="slide-header"><h2 class="slide-title">...</h2></header>
    <div class="slide-content">
      <div class="grid-3">
        <div class="card reveal">
          <div class="card-icon">🚀</div>
          <h3 class="card-title">标题</h3>
          <p class="card-body">1 句话说明</p>
        </div>
        ... x3
      </div>
    </div>
  </div>
</section>
```

**注意**：
- 卡片间距 32-40px（gap）
- 卡片 padding 24-32px（不要 16，太挤）
- 卡片背景同色或 1px 边框 + 浅灰底，不要每张一个色
- 卡片之间的高度必须一致（flex + align-items: stretch）

## 6. Formula / Code（公式 / 代码块）

**用途**：数学推导 / API 示例 / 关键代码。

**骨架（公式）**：
```html
<div class="academic-box">
  <h3 class="box-title">1. 公式名</h3>
  <div class="formula-container">
    <math display="block">...</math>
  </div>
</div>
```

**骨架（代码）**：
```html
<div class="code-block">
  <div class="code-header">~/path/to/file.sh</div>
  <pre><code>...</code></pre>
</div>
```

**注意（公式）**：
- 容器 `overflow: visible`，加 `padding-bottom: 10-14px` 留出下标空间
- `display="block"` 是 MathML 的必要属性
- 字号 28-40px 起步，长公式拆行
- 多个公式共用 slide 时，box 间距 12-16px

**注意（代码）**：
- 等宽字体，必给 `<pre>` 设 `white-space: pre-wrap`
- 高亮用 token class，不要全用 inline style
- 行号可选；超 30 行要拆

## 7. Quote（引文 / 强调）

**用途**：金句 / 结论 / 转折。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner">
    <div class="academic-quote reveal" contenteditable>
      "一句核心主张。"
    </div>
    <p class="quote-source">— 出处</p>
  </div>
</section>
```

**注意**：
- 引文字号 28-40px；**中文不能用斜体**（浏览器合成的是伪斜体），改用字重 / 颜色 / 缩进 / 引号区分
- 必须有 1 行出处
- 留白 ≥ 30% 上下，避免压迫感

## 8. Final / Thanks（结尾 / 致谢）

**用途**：第 14-17 页。

**骨架**：
```html
<section class="slide">
  <div class="slide-inner">
    <h2 class="final-title reveal-scale" contenteditable>致谢 / Q&A</h2>
    <p class="final-sub">一句话总结 / 联系方式</p>
  </div>
</section>
```

**注意**：
- 字号比章节封更大（80-120px）
- 可加一个"返回封面"按钮（可选）
- 结尾可加鸣谢名单（≤ 5 行）

## 混排节奏建议

```
1 Cover
2 Hook
3 总览
4-5 阶段 1（章节封 + 痛点）
6-9 阶段 2（章节封 + 4 个支撑）
10-12 阶段 3（章节封 + 2-3 个支撑）
13 引文（转折 / 升华）
14 总结
15 致谢
```

> 实际写时按主题灵活组合，但每 4-5 页必须换 1 种 layout，否则全是文字墙。
