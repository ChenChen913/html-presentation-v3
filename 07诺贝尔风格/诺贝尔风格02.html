自揭老底：我用 AI 做了哪些事儿

从 Prompt 到个人记忆系统的范式演进

汇报人：maomaotech25

01. 汇报缘起与核心拷问

  • 外部触发： 行业对 AI 使用深度的核心考核指标。
  • 两个维度的自我审视：
    • 我究竟产出了哪些具有实际价值的工程？
    • Token 的消耗量背后的逻辑与效率是什么？
  • 研究基点： 从单纯的工具使用者，向系统构建者的思维转变。

02. 启蒙期：从单点爆发到 Vibe Coding

  • 初期接入： 聚焦于 Prompt 工程与 AI 图像生成。
  • 代码跃迁： 累计生成 140+ HTML 原型网页。
    • 桌面时钟原型
    • 医院住院系统（经十余次高频迭代打磨）
    • 血压记录工具与数据信息卡片
  • 方法论提炼： 深度交流与微调，完成从单网页到“小项目”的过渡。

03. 独立开发：电子药箱与现实壁垒

  • 落地项目： 家庭电子医药管理系统。
    • 实现说明书记录、分类及过期自动预警。
    • 工具链：Kiro (Spec 模式初探) / ClaudeCode / Trae。
  • 当前开发者的核心痛点：
    • 算力与资金： 顶尖大模型额度消耗极快。
    • 生态局限： Windows 系统难以完美支撑底层 AI CLI 生态（向往 Mac 环境）。

04. Skill 的本质：思维的原子化与辅助记忆

  • 性能定律： Skill 必须依托顶尖模型驱动才能达到极限。
  • 工作流重构： 促使人类将模糊任务精细化拆解。
    • 例：信息获取 -> 数据向量化 -> 分析极值 -> 网页/文档多模态呈现。
  • 认知深化：
    • 独创：融合中医理论的健康管理 Skill、深度知识提取体系。
    • 容错：将 AI 踩坑与报错过程沉淀为专属 Skill，形成机器记忆。

05. 架构哲学：稳定性原则与奥卡姆剃刀

  • 系统复杂度的演进： 网页 (轻度) → Skill (中度) → 项目 (重度)。
  • 杀鸡焉用宰牛刀原则：
    • 能用 Python 脚本解决的任务，绝不滥用 AI Agent。
    • 例：Markdown 中英文自动加空格，代码清洗远胜 Token 消耗。
  • 技术中立观： 破除对大厂 Agent 或 OpenClaw（小龙虾）的盲目神化，只取其无监视、免排队之 API 优势。

06. 终极构想：AI 个人记忆系统 (数字化分身)

  • 超越“前女友/前同事复刻”的整活属性，建立严肃的个人数字资产体系。
  • 三维时空架构模型：
    • 过去： 建立庞大的历史回溯数据库。
    • 现在： 矩阵化日志记录（日常规划 / 健康监测 / 学习复盘）。
    • 未来： 引入 Mirofish 算法机制，基于历史数据对个人决策与发展进行沙盘推演。

07. 未来深水区：底层架构探索

  • Agent 协作矩阵： ClaudeCode Agents Team 的并行与内部通信。
  • Harness (驾驭与调度)： 借鉴古典政治制度（如“三省六部制”）的数字劳动力管理模型。
  • 全终端 CLI 接管：
    • 打造 ClaudeCode (大脑) 联合 Gemini/CodeX (双臂) 的多端协同。
    • 终极断言：未来的 CLI 不再是给人看的，而是给 AI 看的。
