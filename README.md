# html-presentation-v3

把任何主题、大纲或 Markdown 笔记，做成一份**能直接双击打开的单文件 HTML 演示文稿**。

零构建依赖（只引 CDN 字体）、1280×720 基准自动缩放、上下滚动翻页、键盘导航、移动端自适应、页面文字可编辑。

---

## 它能产出什么

- **一个 `.html` 文件** = 一份演示文稿，能邮件附件、能丢网盘、能打印成 PDF。
- 默认 14–17 页，7 种美术风格任选。
- 每一页都严格落在 1280×720 视口里——不出现文字截断、越界、踩 footer 这类常见翻车。

## 两条核心规则（摘自 `references/`）

**三层元素**：装饰层（z=0，背景/形状/模糊，必须 `pointer-events:none`）→ 结构层（z=1，1280×720 帧 + header/footer）→ 内容层（z=10，文字/列表/公式/图片，占视口 60–80%）。

**渐进式披露**：整本按 7:2:1 分配（正文 / 章节封 / 总结致谢）；单页内容按「装饰 → 主标题 → 副标 → 正文 → 强调」分 4 段 stagger 进场；一页只讲一个核心命题。

## 质检

两道关卡，出稿后都要过：

```bash
npm install playwright-core

# 1) 几何：元素有没有越出 1280×720 帧、文字有没有被裁切/截断
node qa_check.js --all                        # 跑全部参考 deck
node qa_check.js path/to/deck.html --shots    # 单个 deck，并逐页截图
node qa_check.js --all --offline              # 掐断 CDN 字体，按系统字体回退再测一遍

# 2) 规则：字体栈 / 字重 / 斜体 / 字号 / 行高 / 对比度 / 引号 / 断行
node rules_check.js                           # 跑全部参考 deck
node rules_check.js path/to/deck.html         # 跑单个
```

两个脚本退出码 0 = 全部通过，非 0 = 有问题的 deck 数。

- `qa_check.js` 检测项：越界 / 纵向裁切 / 横向裁切 / 行数截断 / 帧自身溢出。
- `rules_check.js` 检测项：缺少中文字体栈 / AI 默认英文字体 / 字重 >700 / 伪斜体 / 字号过小 / 行高不达标 / 正文字间距 / 纯黑纯白字 / 对比度不足 / 直角引号 / `break-all` / 缺 `text-wrap`。
- **CDN 字体在国内常不可达**，同一份 deck 会因字体到达时机不同而测出不同结果。`qa_check.js` 测量前会等 `document.fonts.ready`；加 `--offline` 可按系统字体回退再测一遍，两条都要绿。

当前仓库内 10 份 deck（137 页）**两道关卡全绿**。

几点值得单独说的：

- **「标题排版变形」的根源是两条**：101 处标题没有 `text-wrap: balance`（末行长短悬殊、出现孤字），
  以及 2 处标题行高过大（松散）。两者都已修，另外用逐字符行盒测量的方式复查了孤字 / 安全边距 /
  标题纵向位置一致性，10 份 deck 均无问题。
- **07 的 191 处纯黑不是 191 个地方写错**，是一个变量 `--text-main: #000000`。改一处即全好。
- **06 有个真 BUG**：强调字写死白色，遇到白底页就是 1.00:1 完全不可见。
- **02 的扫光装饰会让检测结果漂移**：元素 `left: -100% → 200%` 跑无限动画，父容器是 `overflow: hidden`，
  元素跑到右边时 `scrollWidth` 会被撑到 2 倍以上，测到动画哪一帧结果就不同（实测 0~11 页之间跳）。
  已改为元素贴合面板、只让渐变移动。`qa_check.js` 也加了伪元素 `animation: none` 兜底——
  但**根因在 CSS，脚本只是兜底**；也正因有这层兜底，用现行脚本跑改动前的版本会显示 0。

## 第二轮：版式与分栏

上表的 1318 条是**排印**层面（字号 / 字重 / 对比度 / 引号）。规则全绿不等于版式好看，
第二轮按中文 PPT 的通行做法重修了版式，主要三件事：

### 1. 短标题不再被拆成两行

10 份模板里挖出 **18 处硬编码 `<br>`**，全是 6~9 个字的短标题被手撕成两行
（`释放自主智能体<br>(Agents)` 这类）。规矩改成：**标题默认单行，放不下就降字号，不许插 `<br>`**。

- 一行能放几个字 ≈ 可用宽度 ÷ 字号（中文按 1.0em/字，留 3~5% 余量）
- **分栏页按列宽算，不按内容区整宽算**——最常算错的地方
- 括号里的西文跟主干同行

### 2. `.layout-split` 全部改成 grid（7 份 deck 中招）

`.layout-split` 永远和 `.slide-content` 挂在同一元素上，它没声明方向，就被
`.slide-content` 的 `flex-direction: column` 覆盖了——**所有"左右分栏"页其实都在竖排**。
症状会伪装：标题错位（02 P8 标题跑到 x≈500）、标题莫名折行、正文之间凭空大空白
（06/07 的 P4/P6/P9）。

```css
.layout-split {
  display: grid;
  grid-template-columns: 1fr 1fr;   /* 用 flex:1 1 0% 分不均：1168+40gap 实测 518/610 */
  gap: <原值>; align-items: <原值>; height: 100%;
}
.layout-split > * { min-width: 0; }
```

### 3. 形状容器里的字不再被裁（05）

`clip-path` 裁掉文字**不会触发任何溢出告警**。量过才发现：五角星的内接安全区只有外接框的
**30%×30%**，成句永远塞不进去（`打破对话框的边界！` 要星形宽到 1564px）。
改用「短标签 → 12 角爆炸框（安全区 62%）、成句 → 硬边徽章（≈92%）」，五角星退回纯装饰。
